# 基准触发矩阵 (Benchmark Trigger Matrix)

用来把用户意图映射到需要加载的基准规则。

## 已覆盖类型

- 历史、王朝斗争、宫廷权谋、战争建制：
  - 加载 `historical power struggle / 历史权谋`
- 现实主义、都市、当代奋斗、社会修复：
  - 加载 `contemporary realism / urban reality / 当代现实`
- 悬疑、推理、侦探、谜题、犯罪：
  - 加载 `suspense / mystery / fair-play puzzle / 悬疑推理`
- 古言、职业成长言情、女性职业成长：
  - 加载 `ancient romance / profession-growth / 古言与职业成长`
- 无限流、游戏生存、规则生存、群像策略：
  - 加载 `ensemble game / infinite-flow / rules-based survival / 规则生存`
- 文学、严肃、克制、实验：
  - 加载 `serious / literary / experimental / 文学实验`
- 系统文、金手指爽文、力量幻想：
  - 加载 `system fiction / power fantasy / 系统文爽文`

## 混合模式

如果作品明显混合两种已覆盖类型：

- 选择一个主基准组
- 最多选择一个副基准组
- 把两者写进 `09-style-guide.md`
- 副基准只能补充，不能抹掉主类型承诺

## 未覆盖类型

如果类型没有直接覆盖：

- 加载 `popular-fiction-common-laws.md`
- 按以下决策链找最近基准组：
  1. 先判断主导叙事引擎：权力博弈 / 现实压力 / 未知调查 / 情感关系 / 规则生存 / 力量成长 / 形式实验
  2. 再判断节奏承诺：高刺激快节奏 / 中等节奏有起伏 / 慢热克制
  3. 最后判断读者核心期待：爽感与回报 / 悬念与解谜 / 情感共鸣 / 智识挑战 / 氛围沉浸
  4. 将以上三维映射到已覆盖类型中最接近的基准组
- 把 fallback 选择及其理由写进 `09-style-guide.md`
- 如果三维中有两维指向同一个已覆盖类型，直接采用该类型的基准规则

## 目标模式

偏热度：

- 钩子密度更高
- 延续债更强
- 收束/重开节奏更快

偏口碑：

- 主题余味更强
- 人物增量更深
- 语言和结构纪律更高

双高平衡：

- 同时要求可读性和更深余味

## 动态降权

如果用户明确要求：

- 慢热
- 克制强度
- 反公式
- 实验
- 文学耐心

可以降权但不能取消：

- 钩子密度
- 反转频率
- 刺激强度
- 断章激烈程度

仍然是硬门槛：

- 人物维度
- 逻辑自洽
- 主题落地
- 原创性与合规

## 禁用条件

不要用这个矩阵来辩护：

- 把高刺激节奏强压给克制项目
- 把文学拖滞强压给市场向项目
- 复制基准样本的招牌技巧
