# 叙述口音构建 (Narrative Voice Construction)

在去 AI 校正完成后、文字已经干净但没有方向感时使用。目标不是再加一轮风格规范，而是给叙述者一个**有偏向的说话方式**——让读者感觉到"有一个人在说"，而不是"有一台机器在写"。

## 1. 口音是什么

口音不是风格。风格是大分类（简洁、华丽、冷峻、诙谐），口音比风格小。

口音是叙述者在说每句话时**不自觉的选择偏好**：他在哪种细节上停多久、哪种句型反复出现而不觉得重复、对哪类感官特别迟钝而对哪类特别过敏、玩笑往哪个方向开、紧迫时句子变长还是变短。

这些不是技巧层面的选择。技巧层面选的是"这里该用感官锚点""这里该断章"。口音层面的东西改不掉——同一个人写十本书，这些偏好会反复出现，因为这是他看世界的方式。

**AI 味的核心不是"写得不好"，是"没有人在乎"。** 每一处的处理都正确，但正确的方向是均值的。人类作者不是在"写"，是在"偏执"——对某个方向过度敏感、对另一个方向过度迟钝。他们挡不住自己的偏好。

## 2. 口音参数：七个必须锁定的问题

在项目启动或风格指南定稿时回答。答案不超过一页，存入 `09-style-guide.md`。

### 2.1 叙述者最爱干什么

这是口音的核心引擎。只选一个方向，不能并列。

常见的偏好方向（不限于此）：
- **拆台**：看见任何宏大叙事都手痒，必须亲手戳破。上一句还在往大里说，下一句就用日常逻辑把它拽回地面
- **摆帅**：让主角在压迫性场景里保持偏执的冷静或某个反复出现的姿态，叙述者享受拍自己主角不动声色的帅
- **掘荒诞**：把制度、规则或社会共识里自带的荒谬当正常来叙述，不暂停不解说不额外渲染，让读者自己觉得不对
- **拉家常**：无论多激烈的事件，叙述者都保持一种"坐在门槛上跟你慢慢讲"的语调，不加速，不拔高，不切换成史诗腔
- **用毒**：叙述者本人带着明显的刻薄或怨气，观察人物时习惯性地往坏处想、往难听的词上靠，但读者能感觉到这股刻薄是叙述者的性格，不是作者在恶意
- **咏叹**：叙述者在关键处会从场景里短暂抽离，用一个略高于场景的视角重新审视正在发生的事，给出一种接近判词或诗意的定格

决定了这个偏好后，它在每一章都必须至少出现三次，且不能只在安全段落出现——要在最严肃、最危险、别人最不敢这样写的位置也出现。

### 2.2 比喻的取料池从哪来

定死一个领域。比喻不从外面调，不从通用修辞库里取。

常见取料池（选一个主池）：
- 市井日常（种田、做饭、赶集、还价）
- 江湖生意（镖路、买卖、账目、规矩）
- 官场/职场（公文腔、排号、审批、层级）
- 自然环境（山、水、草木、天气——但要把具体来源固定到书中的特定地理区域）
- 家务/厨房（锅碗、灶台、缝补、打扫）
- 账房/财务（账目、利息、抵押、亏盈）
- 工匠/手艺（打铁、木工、泥瓦、纺织）

**自检**：原封不动挪到另一本书里还能用吗？能用就删。

### 2.3 紧迫时刻句子是变长还是变短

定一个规律，全书不背叛。这不是"写得好"的标准，是叙述者的本能呼吸方式。

- **变短型**：越是命悬一线，句子越碎、越冷、越干。像人在喘气时只能一个词一个词往外吐
- **变长型**：越是压迫性场景，句子反而拉得越长越平静，像在压力下反而进入了某种抽离的观察状态
- **长短交替型**：先短句炸雷，再接一个长句展开解释，每轮压迫都是这个呼吸循环

### 2.4 叙述者对什么钝感、懒得写

选定至少一个"别人会写但我不写"的东西。不是不会写，是不感兴趣。

- 战斗招式细节
- 功法原理与修炼过程
- 自然风景描写
- 服装与外貌精描
- 食物与日常器物
- 建筑与环境陈设
- 内心情感的直接剖析
- 政治格局与势力分布

一个对战斗精细但对食物永远一笔带过的叙述者，和一个反过来的叙述者，是两种口音。

### 2.5 主角内心独白往哪个方向开

不能什么都吐。选定一个方向，所有内心戏往同一个方向偏。

- 往自己倒霉的方向（自嘲型）
- 往制度荒谬的方向（观察者型）
- 往他人愚蠢的方向（刻薄型）
- 往事情划不划算的方向（算账型）
- 往这件事对自己有什么用的方向（实用型）
- 几乎不内心独白，内心戏只通过动作和对白的选择透露（沉默型）

### 2.6 第一句能不能暴露口音

第一章第一句话就应该让读者感受到这个叙述者的偏好方向。不是靠设定信息，是靠**说话方式本身**。

检验标准：遮住书名和设定，只读第一段文字，能不能感觉到"这个叙述者有什么特别的说话方式"？如果能，口音就在。如果不能，开篇还没找到声音。

### 2.7 每章的"多余句子"

每章至少有一到两处"不必要但叙述者忍不住"的句子——不是功能性推进场面，而是叙述者因为自己的偏好而多摸了两下、多停了一拍、多说了一句不该在那儿说的话。

如果一章从头到尾每个句子都是功能性的（推进场面、揭示信息、控制节奏），这一章就没有口音。

## 3. 口音自检方法

### 3.1 偏好密度检查（逐章）

- 2.1 选定的核心偏好，本章至少出现了三次吗？
- 2.2 的比喻取料池，有没有比喻跑偏到其他领域？
- 2.4 列出的"钝感项"，是否又被仔细描写了？（如果是，要么删，要么承认这是新的敏感方向并更新口音参数）
- 2.7 的"多余句子"，本章至少有一处吗？

### 3.2 均值出口警报

以下信号说明口音正在滑回均值，需要回头加固：
- 本章最精彩的三句话，换到另一本书里同样精彩且不违和
- 叙述者在严肃段落和搞笑段落的语气差距太小，像是同一层修辞打磨的
- 所有人物在对话里的措辞精度、句型长度、修辞程度高度一致
- 章节结构上的"好"是均匀分配的，没有某一处被过度投入、某一处被草草带过

### 3.3 活人对比测试

写完一页后，找一到两本口音方向完全不同的活人小说，问自己：如果换成那本书的叙述者来写这一页，至少哪三句会写得不一样？如果答案是"哪句都差不多"，说明这一页的叙述者还在用平均值说话，没有选择。

## 4. 与 de-AI 校正的关系

口音构建不是替代 de-AI 校正，是给 de-AI 校正的第三轮（"把人味和现场感补回来"）提供方向。

- de-AI 校正负责**减法**：砍假深刻、砍术语墙、砍通用比喻
- 口音参数负责**方向**：补回来的细节往哪个方向偏、比喻从哪个池取、节奏往哪个规律靠

没有口音参数，de-AI 的"补回来"会在所有可选方向里取均值，结果就是干净但没口音。

## 5. 加载时机

- **新书**：在 `09-style-guide.md` 定稿时，把七个问题的答案写入风格指南。之后每一章起草和去 AI 校正时，口音参数与风格指南一起加载
- **续写既有书**：从已有章节里逆向抽取口音参数——找出已经存在的偏好方向（哪怕只有三处），把它明确化、放大化，而不是从零定义一个可能跟已有正文打架的新口音
- **既有书已有口音但未被明确写入风格指南时**：先做逆向抽取，再把结果写回 `09-style-guide.md`
