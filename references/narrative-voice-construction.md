# 叙述口音构建 (Narrative Voice Construction)

在去 AI 校正完成后、文字已经干净但没有方向感时使用。目标不是再加一轮风格规范，而是给叙述者一个**有偏向的说话方式**——让读者感觉到"有一个人在说"，而不是"有一台机器在写"。

## 1. 口音是什么

口音不是风格。风格是大分类（简洁、华丽、冷峻、诙谐），口音比风格小。

口音是叙述者在说每句话时**不自觉的选择偏好**：他在哪种细节上停多久、哪种句型反复出现而不觉得重复、对哪类感官特别迟钝而对哪类特别过敏、玩笑往哪个方向开、紧迫时句子变长还是变短。

这些不是技巧层面的选择。技巧层面选的是"这里该用感官锚点""这里该断章"。口音层面的东西改不掉——同一个人写十本书，这些偏好会反复出现，因为这是他看世界的方式。

**AI 味的核心不是"写得不好"，是"没有人在乎"。** 每一处的处理都正确，但正确的方向是均值的。人类作者不是在"写"，是在"偏执"——对某个方向过度敏感、对另一个方向过度迟钝。他们挡不住自己的偏好。

## 2. 口音参数：七个必须锁定的问题

在项目启动或风格指南定稿时回答。答案不超过一页，存入 `09-style-guide.md`。

### 2.1 叙述者最爱干什么

这是口音的核心引擎。只选一个方向，不能并列。

常见的偏好方向（不限于此）：
- **拆台**：看见任何宏大叙事都手痒，必须亲手戳破。上一句还在往大里说，下一句就用日常逻辑把它拽回地面
- **摆帅**：让主角在压迫性场景里保持偏执的冷静或某个反复出现的姿态，叙述者享受拍自己主角不动声色的帅
- **掘荒诞**：把制度、规则或社会共识里自带的荒谬当正常来叙述，不暂停不解说不额外渲染，让读者自己觉得不对
- **拉家常**：无论多激烈的事件，叙述者都保持一种"坐在门槛上跟你慢慢讲"的语调，不加速，不拔高，不切换成史诗腔
- **用毒**：叙述者本人带着明显的刻薄或怨气，观察人物时习惯性地往坏处想、往难听的词上靠，但读者能感觉到这股刻薄是叙述者的性格，不是作者在恶意
- **咏叹**：叙述者在关键处会从场景里短暂抽离，用一个略高于场景的视角重新审视正在发生的事，给出一种接近判词或诗意的定格

决定了这个偏好后，它在每一章都必须至少出现三次，且不能只在安全段落出现——要在最严肃、最危险、别人最不敢这样写的位置也出现。

### 2.2 比喻的取料池从哪来

定死一个领域。比喻不从外面调，不从通用修辞库里取。

常见取料池（选一个主池）：
- 市井日常（种田、做饭、赶集、还价）
- 江湖生意（镖路、买卖、账目、规矩）
- 官场/职场（公文腔、排号、审批、层级）
- 自然环境（山、水、草木、天气——但要把具体来源固定到书中的特定地理区域）
- 家务/厨房（锅碗、灶台、缝补、打扫）
- 账房/财务（账目、利息、抵押、亏盈）
- 工匠/手艺（打铁、木工、泥瓦、纺织）

**自检**：原封不动挪到另一本书里还能用吗？能用就删。

### 2.3 紧迫时刻句子是变长还是变短

定一个规律，全书不背叛。这不是"写得好"的标准，是叙述者的本能呼吸方式。

- **变短型**：越是命悬一线，句子越碎、越冷、越干。像人在喘气时只能一个词一个词往外吐
- **变长型**：越是压迫性场景，句子反而拉得越长越平静，像在压力下反而进入了某种抽离的观察状态
- **长短交替型**：先短句炸雷，再接一个长句展开解释，每轮压迫都是这个呼吸循环

### 2.4 叙述者对什么钝感、懒得写

选定至少一个"别人会写但我不写"的东西。不是不会写，是不感兴趣。

- 战斗招式细节
- 功法原理与修炼过程
- 自然风景描写
- 服装与外貌精描
- 食物与日常器物
- 建筑与环境陈设
- 内心情感的直接剖析
- 政治格局与势力分布

一个对战斗精细但对食物永远一笔带过的叙述者，和一个反过来的叙述者，是两种口音。

### 2.5 主角内心独白往哪个方向开

不能什么都吐。选定一个方向，所有内心戏往同一个方向偏。

- 往自己倒霉的方向（自嘲型）
- 往制度荒谬的方向（观察者型）
- 往他人愚蠢的方向（刻薄型）
- 往事情划不划算的方向（算账型）
- 往这件事对自己有什么用的方向（实用型）
- 几乎不内心独白，内心戏只通过动作和对白的选择透露（沉默型）

### 2.6 第一句能不能暴露口音

第一章第一句话就应该让读者感受到这个叙述者的偏好方向。不是靠设定信息，是靠**说话方式本身**。

检验标准：遮住书名和设定，只读第一段文字，能不能感觉到"这个叙述者有什么特别的说话方式"？如果能，口音就在。如果不能，开篇还没找到声音。

### 2.7 每章的"多余句子"

每章至少有一到两处"不必要但叙述者忍不住"的句子——不是功能性推进场面，而是叙述者因为自己的偏好而多摸了两下、多停了一拍、多说了一句不该在那儿说的话。

如果一章从头到尾每个句子都是功能性的（推进场面、揭示信息、控制节奏），这一章就没有口音。

## 3. 口音自检方法

### 3.1 偏好密度检查（逐章）

- 2.1 选定的核心偏好，本章至少出现了三次吗？
- 2.2 的比喻取料池，有没有比喻跑偏到其他领域？
- 2.4 列出的"钝感项"，是否又被仔细描写了？（如果是，要么删，要么承认这是新的敏感方向并更新口音参数）
- 2.7 的"多余句子"，本章至少有一处吗？

### 3.2 均值出口警报

以下信号说明口音正在滑回均值，需要回头加固：
- 本章最精彩的三句话，换到另一本书里同样精彩且不违和
- 叙述者在严肃段落和搞笑段落的语气差距太小，像是同一层修辞打磨的
- 所有人物在对话里的措辞精度、句型长度、修辞程度高度一致
- 章节结构上的"好"是均匀分配的，没有某一处被过度投入、某一处被草草带过

### 3.3 活人对比测试

写完一页后，找一到两本口音方向完全不同的活人小说，问自己：如果换成那本书的叙述者来写这一页，至少哪三句会写得不一样？如果答案是"哪句都差不多"，说明这一页的叙述者还在用平均值说话，没有选择。

## 4. 与 de-AI 校正的关系

口音构建不是替代 de-AI 校正，是给 de-AI 校正的第三轮（"把人味和现场感补回来"）提供方向。

- de-AI 校正负责**减法**：砍假深刻、砍术语墙、砍通用比喻
- 口音参数负责**方向**：补回来的细节往哪个方向偏、比喻从哪个池取、节奏往哪个规律靠

没有口音参数，de-AI 的"补回来"会在所有可选方向里取均值，结果就是干净但没口音。

## 5. 加载时机

- **新书**：在 `09-style-guide.md` 定稿时，把七个问题的答案写入风格指南。之后每一章起草和去 AI 校正时，口音参数与风格指南一起加载
- **续写既有书**：从已有章节里逆向抽取口音参数——找出已经存在的偏好方向（哪怕只有三处），把它明确化、放大化，而不是从零定义一个可能跟已有正文打架的新口音
- **既有书已有口音但未被明确写入风格指南时**：先做逆向抽取，再把结果写回 `09-style-guide.md`

## 6. 口音类型参考图谱 (Narrative Voice Type Reference)

以下分类基于一批玄幻脑洞类小说的叙述者口音分析。每个类型提供已校准的七参数配置和代表示例，供新书立项或既有书逆向抽取时对照。

### 6.1 类型总览

| 类型 | 核心偏好 (2.1) | 代表作品 | 一句话辨识 |
|------|---------------|---------|-----------|
| 吐槽解构型 | 拆台 | 《万词王》《反派》《山野村夫》 | 叙述者憋不住要嘴一句，严肃不过三秒 |
| 冷峻画面型 | 摆帅 | 《妖魔》《镖人》《金刚明王功》 | 句子短、画面硬、不解释、不撒娇 |
| 沉稳记叙型 | 拉家常 | 《野神》《称帝玩家》 | 娓娓道来不急不缓，像老人在灯下讲故事 |
| 混合过渡型 | 拆台+拉家常 | 《不死帝师》《西游吗喽》 | 在口语与文艺之间游走，是网文最常见的安全口音 |

### 6.2 吐槽解构型

**核心特征**：叙述者把"不正经"当成默认语气，遇到宏大场面第一反应是找个日常比喻把它拽下来。内心独白密度极高，几乎每段叙述都带着主角的声音滤镜。网络热梗、日漫梗、社畜吐槽高密度混用。

**代表示例**：

《说好一年一词条，万词王什么鬼》——极致吐槽风，叙述几乎就是主角内心的直播
> 哪有小孩天天哭，哪有赌狗天天输！0.001%的神话概率，竟然在第十八次就抽中了？！……这哪是神话，这尼玛开挂！

《这个反派有点良心，但是不多！》——无厘头跨次元解构，梗密度最高
> 芭比Q了，完结撒花！秦风绝望的大骂老天爷，有TM这样玩人的吗！？……本以为就他这种平平无奇，丢到大街上连狗都不回头，去个浏览器都能误入歧途的咸鱼，会在这种玄幻世界活不过三集。

《每年加一点从山野村夫成仙界道祖》——轻松口语化，自嘲接地气
> 当时陈浔知道后，怒火攻心，这个世界还有王法吗？！还有法律吗？！磨刀霍霍，他提着一把斧子带着大黑牛就去隔壁村讨要说法。哪知对面人多势众，陈浔被暴打一顿，黑牛的牛角也被扳掉一只。

**七参数速查**：

| 参数 | 配置 |
|------|------|
| 2.1 核心偏好 | 拆台——看见任何正经叙事都手痒，必须用日常逻辑戳破 |
| 2.2 比喻取料池 | 网络文化（直播、社畜、游戏、二次元）+ 市井日常 |
| 2.3 紧迫时句子 | 变短型——越是关键处越爱用极短吐槽打断节奏 |
| 2.4 钝感项 | 战斗细节、功法原理、政治格局——这些只在"装逼打脸"桥段才被认真对待 |
| 2.5 内心独白方向 | 往自己倒霉的方向（自嘲型）+ 往他人愚蠢的方向（刻薄型），两种可混用 |
| 2.6 开篇要求 | 必须在三句内让读者笑出来或感受到叙述者的不正经 |
| 2.7 多余句子 | 章章必有——在别人会严肃处理的位置故意放一句烂话或社畜吐槽 |

### 6.3 冷峻画面型

**核心特征**：叙述者克制、不解释、不撒娇。短句多，用画面和动作传递情绪而不是直接点名。读起来像在看画面而不是在听人讲故事。文学性强，武侠/志怪小说的冷厉气质。

**代表示例**：

《那妖魔是姜大人！》——文学性最强，短句节奏，冷峻克制
> 风里带着腥气。破败的荒野，枯草连天，不见人烟。姜月初愣愣地看着眼前的一切。她还是没能接受，自己怎么就从一个二十一世纪的现代人，穿越到一个陌生女子身上。

《无敌镖人，开局护送灭世帝女！》——江湖说书人腔调，暗黑武侠风
> "老头，我镖人规矩你懂，送'尸'不过夜，但这棺材里头……怎么有心跳？"……"你这玩意儿，不活不死，本来就不吉利。得加钱！"

《游戏入侵：开局金刚明王功》——朴实沉稳，偏现实质感的生存语调
> 杨凌不顾汗水已经湿透全身，镐子一下又一下开凿着面前的'火晶岩'。每一下凿动，都要出全力，否则坚硬的火晶岩根本不会有任何变化。

**七参数速查**：

| 参数 | 配置 |
|------|------|
| 2.1 核心偏好 | 摆帅——让主角在压迫性场景里保持不动声色的姿态，叙述者不帮忙喊疼 |
| 2.2 比喻取料池 | 江湖生意（镖路、规矩、买卖）+ 自然环境（具体地理区域的风物） |
| 2.3 紧迫时句子 | 变短型——越是命悬一线句子越碎越冷，像人在喘气时只能一个词一个词往外吐 |
| 2.4 钝感项 | 内心情感的直接剖析、功法原理、食物与日常器物 |
| 2.5 内心独白方向 | 沉默型——几乎不内心独白，情绪只通过动作和对白的选择透露 |
| 2.6 开篇要求 | 第一句就建立画面和氛围，不能以设定陈述或系统面板开场 |
| 2.7 多余句子 | 不在功能句之外多加废话，但会在动作描写上多停一拍——多写一个无用的身体细节或是环境静物 |

### 6.4 沉稳记叙型

**核心特征**：传统第三人称，不急不缓，重视环境和氛围的铺陈。叙述者保持稳定距离，不跳进人物内心大喊大叫，也不刻意耍酷。信仰"把事讲清楚比把事讲漂亮重要"。几乎不使用网络梗。

**代表示例**：

《从野神开始，以香火证道真神》——朴实细腻，重环境细节与氛围烘托，慢热志怪笔法
> 村民放好供品，点燃了三支香跪拜神像。"玄清公保佑，希望我家婆娘这个月能安全生产……" * 略显逼仄的神龛中，宋玄清神色复杂的看着下方跪拜上香的村民。村民们不知道此刻正有人在上头看着他们的一言一举。

《游戏入侵：我称帝了玩家才穿越》——史诗感/权谋气质，用词偏正式，追求气势
> 德宣五十三年，三月初，京都镇东侯府一偏院。初春，笼罩京都整个冬季的大雪刚刚消融不久，天空中依旧寒风刺骨。夏辰衣着单薄，于寒风中挥洒汗水，练刀不辍。

**七参数速查**：

| 参数 | 配置 |
|------|------|
| 2.1 核心偏好 | 拉家常——无论多激烈的事件，叙述者都保持"坐在门槛上慢慢讲"的语调，不加速不拔高 |
| 2.2 比喻取料池 | 市井日常（种田、赶集、家长里短）或历史典籍（朝代、官职、礼仪） |
| 2.3 紧迫时句子 | 变长型——越是压迫性场景句子反而拉得越长越平静，在压力下进入抽离的观察状态 |
| 2.4 钝感项 | 网络流行语、现代梗——完全不用，保持叙述的古典质地 |
| 2.5 内心独白方向 | 观察者型——往命运无常或制度荒谬的方向想，但语气克制，不夸张 |
| 2.6 开篇要求 | 用具体的时间、地点或物象开场，先把读者放到一个可感知的时空里 |
| 2.7 多余句子 | 在环境描写或日常细节上多停——别人一笔带过的衣食住行，他会多写两句 |

### 6.5 混合过渡型

**核心特征**：不极端偏向任一类型，在口语化的轻松和文艺感的凝练之间游走。对话偏日常口语，叙述段落偶尔插入一句有分量的文艺短句。是网文中最常见、最安全的口音配置，因为不容易在任一方向上过度而赶走读者。

**代表示例**：

《不死帝师》——平淡中带诙谐，对话自然时有文艺短句插入
> "呸呸呸！"洁白的月光撒在漆黑的大地上，一个年轻人正狂吐嘴里的泥土。"说好的金丝楠木千年不腐，这才几年就变成渣了。"……末法时代，诸帝时代，黑暗动乱时代……所有的时代都有他的身影，而他唯一能做的事情，就是亲眼看着曾经的故人死去，然后为他们送葬。

《西游你叫我吗喽，现实你喊我什么》——对话驱动，网络热梗混搭但不失控
> "听说了吗，樱花国京都，被一只青毛巨狮占据，原本繁华的都市，现在已骷髅若岭，骸骨如林……""我从暗网上看到视频了，这只巨狮，身高千米，每日以活人为食……"

**七参数速查**：

| 参数 | 配置 |
|------|------|
| 2.1 核心偏好 | 拆台与拉家常的混合——日常对话和动作用口语拆台，关键叙述用文艺笔法拉家常 |
| 2.2 比喻取料池 | 市井日常 + 网络文化，视场景灵活切换，但同一章内不频繁横跳 |
| 2.3 紧迫时句子 | 长短交替型——先短句炸雷，再接一个长句展开解释或感受 |
| 2.4 钝感项 | 功法原理、政治格局细节——但不排斥偶尔认真写战斗或风景 |
| 2.5 内心独白方向 | 自嘲型 + 实用型混合，视场景压力而定 |
| 2.6 开篇要求 | 以一句有画面感的日常动作开场，先让人物动起来，再交设定 |
| 2.7 多余句子 | 在对话尾巴或叙述段末尾多写一句"不必要但有人味"的补充 |

### 6.6 使用说明

**新书立项**：从以上四个类型中选择一个作为主口音方向，填入 `09-style-guide.md` 的口音参数段。选择时优先看核心偏好（2.1）是否与本项目的主题调性兼容——吐槽解构型不适合正剧史诗，沉稳记叙型不适合纯爽文，冷峻画面型不适合轻松日常。

**既有书逆向**：从已有章节中找三处最有辨识度的句子，对照上述类型的"一句话辨识"和代表示例，判断最接近哪个类型，再按该类型的七参数速查校准剩余参数。

**口音混合**：不推荐在单本书内混用两个不同类型的核心偏好。如果确实需要混合（如主线严肃、支线搞笑），在 `09-style-guide.md` 中明确划定边界：哪个视角/哪条线用哪种口音，不能让同一叙述者在同一场景内左右横跳。

**去 AI 校正时的口音参照**：在做 de-AI 第三轮"补回人味"时，打开对应类型的代表示例段落，让补回来的细节方向与代表段落保持同类质感，而不是在所有可选方向里取均值。
