# 钩子选型决策矩阵

在生成章节控制卡的 `chapter_end_hook` 字段前使用本文件。只做选型，不涉及具体写法。

## 第一步：判断本章钩子需要承担什么功能

章尾钩子只选一个主要功能，最多加一个次要功能：

| 功能 | 含义 | 适用信号 |
|------|------|----------|
| **前拉** | 让读者必须翻下一章 | 本章非卷末收束章；下一章有强转折或揭示 |
| **定价** | 改变读者对本章已发生事件的理解 | 表面平静但暗藏信息；本章结尾露出冰山一角 |
| **收束** | 给一段弧线一个临时落点 | 本章是一个小阶段的终点；下一章将换线或换节奏 |
| **开启** | 引入新压力或新变量 | 本章已解决旧压力；需要新钩子接力 |
| **回响** | 呼应前文的某个意象或承诺 | 前文埋过与此章关联的伏笔或母题 |

## 第二步：按故事阶段选钩子类型

| 故事阶段 | 推荐钩子类型 | 强度 | 原因 |
|----------|-------------|------|------|
| 第1章 | 截断 / 突然揭示 / 危机升级 | 强 | 必须建立"必须读下一章"的冲动 |
| 2-3章 | 选择 / 信息差 / 情感转折 | 强 | 开始建立人物投入和长线好奇 |
| 前期铺陈（10-30章） | 信息差 / 身份即将揭露 / 对话悬念 | 中 | 铺线为主，钩子保追读不抢戏 |
| 中期日常/过渡 | 对话悬念 / 隐藏含义 / 意象钩子 | 中低 | 保持微压力，不给假高潮 |
| 高潮前蓄力 | 危机升级 / 悬念预知 / 倒计时 | 强 | 需要积蓄压力 |
| 高潮章 | 截断 / 两难抉择 / 留白 | 极强 | 不能泄压 |
| 高潮后回稳 | 情感转折 / 回声钩子 / 留白 | 中低 | 收束为主，给读者呼吸 |
| 卷末收束 | 时间跳跃 / 回声钩子 / 留白 | 收束 | 落点而非新坑 |

## 第三步：按本章场景压力类型映射

| 本章压力落点 | 钩子方向 | 示例 |
|-------------|----------|------|
| 揭示了一个真相 | 突然揭示 / 隐藏含义 | 真相的一句话，但不说后果 |
| 人物做了艰难选择 | 两难抉择 / 留白 | 选的瞬间截断，不写后果 |
| 危机正逼近但未到 | 倒计时 / 紧急危机 | 逼近的信号，不说结果 |
| 身份或关系在变化边缘 | 身份反转 / 情感转折 | 对方的一个反应，主角未察觉 |
| 获得关键物品或线索 | 神秘物品/线索 / 信息差 | 物品出现，但不解释 |
| 对话中有暗流 | 隐藏含义 / 对话悬念 | 一句话有两个意思 |
| 安静收束需要余味 | 意象钩子 / 回声钩子 / 留白 | 一个意象变化或回响 |

## 第四步：排除检查

- 本章钩子与上一章类型相同？→ 换一种。同一类型不能连用超过 2 章
- 钩子强度超过本章实际压力？→ 降级。过渡章不强做大钩子
- 钩子是假威胁（下章立刻解除）？→ 必须换。假悬念比没悬念更毒
- 钩子需要下章前 500 字内兑现？→ 确认下章确实有这个安排

## 选型输出格式

在控制卡中记录：

```
chapter_end_hook:
  primary_function: [前拉/定价/收束/开启/回响]
  secondary_function: [可选]
  hook_type: [类型名]
  hook_intensity: [强/中/低/收束]
  one_line: [钩子一句话描述——本章最后读者看到或感到什么]
```
